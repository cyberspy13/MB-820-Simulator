# MB-820 Exam Simulator

A practice exam player that runs in the browser. Upload your own questions, set up the exam, skip and flag questions, review them, and get a score report.

- **Exam setup:** a whole exam, chosen sections, a number of questions, a range, or the questions you got wrong before, with training mode and a timer
- **During the exam:** skip, flag for review, show answer, calculator, zoom, save and resume
- **Question types:** single and multiple choice, matching, Yes/No, complete the code, put in order
- **Upload:** PDF, Word (.docx, .doc), Excel (.xlsx, .xls), CSV, PowerPoint (.pptx), OpenDocument (.odt, .ods, .odp), RTF, HTML, TXT or MD files, or a file exported from the simulator. Word, Excel and text templates can be downloaded in the upload window.

No questions are included apart from eight original samples. Files you upload are read in your browser and stay there; nothing is sent to a server.

To run it without a website, open `index.html`. To check it, open `tests/tests.html`.
